# Archive

Content kept out of the site build (Hugo only reads `content/`).

- `publication/` — publications before 2025, generated from the members' Google Scholar
  profiles and completed with Crossref (DOI, full author lists). The Publications page lists
  papers from 2025 on (`from_year` in `content/publications.md`). To show older papers again,
  move the folders back to `content/publication/` and lower `from_year`.
